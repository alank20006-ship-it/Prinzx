# Level Up Fitness — Android Project

This is a native Android WebView wrapper around the Level Up Fitness web app.

## Included
- app/src/main/assets/index.html
- app/src/main/assets/style.css
- app/src/main/assets/app.js
- Android WebView launcher activity
- Gradle Android project

## Build
Open this project in Android Studio or an online Android build service.
The app loads the website locally from Android assets, so the core app works without hosting the website.

Application ID:
com.levelupfitness.app

Version:
1.0 (versionCode 1)
